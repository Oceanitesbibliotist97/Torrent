## Зачем

Большинство торрент-клиентов показывают рекламу, предлагают сторонние программы, проверяют обновления, отправляют отчёты о сбоях и аналитику. Многие к тому же сообщают всему рою, кто вы. Этот клиент — один файл `Torrent.exe`, который запускается из любой папки или с флешки:

- **Никакой телеметрии.** Ни аналитики, ни отчётов о сбоях, ни проверок обновлений, ни аккаунтов, ни идентификаторов. Приложение никогда не связывается с авторами.
- **Портативно и без следов.** Настройки и данные для продолжения загрузок лежат в `TorrentData\` рядом с программой. Реестр не затрагивается. Удалите папку — и следов не останется.
- **Честная приватность.** «Центр приватности» в реальном времени показывает, что защищено, и прямо говорит, что не может скрыть ни один BitTorrent-клиент.

## Возможности

**Приватность и защита сети**

| | |
|---|---|
| Привязка к VPN + kill switch | Все сокеты (пиры, трекеры, DHT, веб-сиды, DNS) привязаны к VPN-адаптеру. Если VPN отключится, загрузки мгновенно остановятся и через обычное подключение ничего не уйдёт. После переподключения они продолжатся. |
| SOCKS5-прокси | Трафик пиров и трекеров идёт через прокси. Имена разрешает прокси, локальные DNS-запросы заблокированы, а DHT, UDP-трекеры, uTP и входящие соединения отключены, чтобы ничего не шло в обход. |
| Анонимный режим | Случайный 20-байтный peer ID; ни названия, ни версии клиента в рукопожатиях и запросах к трекерам (даже HTTP User-Agent пустой). |
| Шифрование протокола | Обязательно по умолчанию. После обфусцированного рукопожатия весь поток шифруется RC4, и шейпинг провайдера его не распознаёт. |
| WebRTC отключён | WebTorrent/WebRTC может раскрыть настоящий IP через STUN, поэтому отключён навсегда. |
| UPnP / NAT-PMP выключены | Роутер не просят открыть порт, пока вы сами не включите (с VPN и прокси — никогда). |
| Приватные торренты (BEP 27) | Работают в отдельном экземпляре движка без DHT и обмена пирами. |
| Режим без истории | По желанию список загрузок и данные продолжения удаляются при выходе. |
| Блок-листы IP | Загрузка списка в формате P2P (текст или `.gz`) с диска. Ничего не скачивается. |

**Безопасность**

- Magnet-ссылки и `.torrent`-файлы считаются недоверенными: лимиты размера, строгий разбор, отбрасываются адреса трекеров и веб-сидов в локальной сети (никакого сканирования LAN), отклоняются испорченные URL трекеров, способные уронить движок.
- Исполняемые файлы и имена, замаскированные символами смены направления текста (`report‮fdp.exe`), подсвечиваются до начала загрузки.
- Готовые файлы получают метку Windows **Mark of the Web**, поэтому их проверяют SmartScreen и защищённый просмотр Office. Адрес источника не записывается.
- Удаление файлов ограничено папкой загрузки, в том числе при наличии junction-ссылок.
- Пароль прокси шифруется через Windows DPAPI и никогда не передаётся обратно в интерфейс.
- Интерфейс общается с Go через внутрипроцессный IPC. **Локального веб-сервера нет**, и ни другая программа, ни сайт не могут к нему обратиться. Строгая Content-Security-Policy разрешает только встроенные скрипты, а недоверенный текст выводится как текст, а не HTML.
- Внешние страницы открываются только из фиксированного белого списка (ссылки для пожертвований).
- DLL загружаются только из System32, что защищает портативную программу от подброшенных рядом библиотек.

**Удобство**

- Английский и русский языки с правильными формами множественного числа; тёмная, светлая или системная тема.
- Перетаскивание `.torrent`-файлов, вставка magnet-ссылок через <kbd>Ctrl</kbd>+<kbd>V</kbd>, выбор файлов перед загрузкой.
- Сортируемый список с мультивыбором, контекстное меню, панель деталей (обзор, файлы с приоритетами, пиры, трекеры).
- Горячие клавиши: <kbd>Ctrl</kbd>+<kbd>O</kbd> открыть, <kbd>Ctrl</kbd>+<kbd>U</kbd> magnet, <kbd>Пробел</kbd> пауза/продолжить, <kbd>Del</kbd> удалить, <kbd>Ctrl</kbd>+<kbd>F</kbd> поиск, <kbd>Ctrl</kbd>+<kbd>,</kbd> настройки.

## Честно о границах

- Любой пир, с которым вы обмениваетесь данными, узнаёт IP-адрес, с которого вы подключаетесь. **Изменить этот адрес может только VPN или прокси.** Шифрование и анонимный режим этого не делают.
- VPN-провайдер видит ваш трафик. Выбирайте сервис с проверенной политикой отсутствия логов, разрешающий P2P.
- Интерфейс работает в Microsoft Edge WebView2 — системном компоненте Windows. Приложение загружает только локальное содержимое и отключает проверку адресов SmartScreen, но сама среда выполнения следует вашим настройкам диагностических данных Windows.
- Средства приватности не делают нарушение авторских прав законным. Соблюдайте законы своей страны.

## Скачать и проверить

Каждый релиз содержит `Torrent.exe` и `Torrent.exe.sha256`. Проверьте перед запуском:

```powershell
(Get-FileHash .\Torrent.exe -Algorithm SHA256).Hash.ToLower()
```

Требования: Windows 10 или 11 (x64) с WebView2 Runtime (предустановлен в актуальных версиях Windows).

## Сборка из исходников

Нужен Go 1.26 или новее. Компилятор C и Node.js не требуются.

```powershell
.\build.ps1 -Version 1.0.0      # проверки, тесты и сборка build\bin\Torrent.exe
```

Сборка выполняется на чистом Go (`CGO_ENABLED=0`) с `-trimpath`: в бинарнике нет путей с машины сборки, и его можно воспроизвести.

Для работы над интерфейсом запустите его с мок-бэкендом в любом браузере:

```powershell
go run ./tools/preview          # http://127.0.0.1:34115/?lang=ru&theme=light&mode=vpn
```
